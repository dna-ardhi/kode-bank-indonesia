Semua {stats.total} institusi ada di bawah. Ketik nama, kode bank, atau BIC (misalnya `mandiri`, `014`, atau `CENAIDJA`), lalu saring menurut jenis atau kategori. Klik nama untuk melihat JSON mentah record itu.

Kolom **Verified** menunjukkan apakah record sudah terkonfirmasi. Baca [artinya](../../reference/verified/) sebelum memakai kodenya.
