## The code

The list comes from the API. Only `active` institutions are shown to the user, and a warning appears when a record isn't `verified`:

```ts
const { data } = await fetch("https://dna-ardhi.github.io/kode-bank-indonesia/v1/all.json").then((r) => r.json());

const q = input.value.trim().toLowerCase();
const results = data
  .filter((r) => r.status === "active")
  .filter((r) => [r.display_name, ...r.aliases].some((n) => n.toLowerCase().includes(q)) || r.bank_code === q)
  .slice(0, 8);

function pick(bank) {
  bankCode.textContent = bank.bank_code ?? "none yet";
  accountLabel.textContent = bank.account_number.label; // "Nomor rekening" or a phone number
  warning.hidden = bank.verified; // show a note when it isn't verified
}
```

:::caution
The holder name in this form is **just passed along as typed**. Confirming that a name matches an account number needs a paid *account inquiry* API. See the [FAQ](../faq/).
:::
