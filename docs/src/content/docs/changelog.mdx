## Kebijakan versi

Dataset mengikuti semver, dan versinya sama dengan field `version` di setiap respons API. Tag tidak dipublikasikan ke npm.

- **Patch:** perubahan data (record baru, koreksi, atau penonaktifan).
- **Minor:** field opsional atau endpoint baru.
- **Major:** perubahan yang merusak, sekaligus path `/vN` baru.

## 1.0.0 — 20 November 2026

Rilis pertama.

- API statis `/v1`: `all`, `banks`, `ewallets`, `by-id/{id}`, dan `meta`.
- {stats.total} record: {stats.banks} bank dan {stats.ewallets} e-wallet, {stats.verified} di antaranya `verified`.
- Paket npm ber-TypeScript dengan `all`, `banks`, `ewallets`, `findById`, dan `search`.
- Sinkronisasi mingguan dengan daftar peserta BI-FAST dan SKNBI Bank Indonesia.

## Paket npm dihentikan

Paket npm `kode-bank-indonesia` (beserta mirror jsDelivr/unpkg) tidak lagi dipublikasikan, karena hanya diperbarui lewat rilis manual dan bisa tertinggal dari API. 1.0.1 adalah versi terakhirnya. Pakai API statis saja: [mulai cepat](../quick-start/).
