## Kebijakan versi

Dataset mengikuti semver, dan versinya sama dengan field `version` di setiap respons API.

- **Patch:** perubahan data (record baru, koreksi, atau penonaktifan).
- **Minor:** field opsional atau endpoint baru.
- **Major:** perubahan yang merusak, sekaligus path `/vN` baru.

## 1.0.0 — 21 November 2026

Rilis pertama.

- API statis `/v1`: `all`, `banks`, `ewallets`, `bprs`, `by-id/{id}`, dan `meta`.
- {stats.total} record: {stats.banks} bank dan {stats.ewallets} e-wallet, {stats.verified} di antaranya `verified`. Ditambah {stats.bprs} BPR dan BPRS di `/v1/bprs.json`.
- `bank_code` dari "Sandi Bank" OJK; nama dan BIC dari daftar peserta BI-FAST Bank Indonesia.
- Sinkronisasi mingguan dengan daftar BI-FAST, SKNBI, OJK, dan direktori QRIS ASPI.
